Core Box Core Shooter

In today’s fast-moving foundry industry, core box core shooter machines play a vital role in achieving precision and efficiency in metal casting. These advanced systems produce high-quality sand cores by injecting a sand-resin mixture into accurately designed core boxes, enabling the creation of complex metal components with intricate internal geometries.

Features

  • Robust design and sturdy construction
  • High dimensional accuracy and precision
  • High strength at thin profiles
  • Sand saving hollow cores
  • Fully automatic PLC based control with display unit
  • Fault diagnostics for troubleshooting
  • Safety enclosure, laser beam safety curtain and safety interlocks
  • Electric or gas heaters provided
  • Auto core ejection mechanism
  • Both pneumatic and hydraulic models available

One Half Fixed And One Half Moving

This machine is provided with bottom carrier trolley and top lifter assembly. The bottom half of the core box is fixed on core carrier trolley while the top half is movable. At the beginning of cycle, both halves of core box enter machine on the core carrier trolley. After shooting, gassing and purging operations the core carrier trolley comes out. The top half is lifted by top lifter assembly. The core can now be collected by the operator.

Horizontal Parted Cold Box Core Shooter With Side Mandrels

These machines are used to manufacture cores using horizontally parted core box. The core box has top and bottom part with a horizontal parting line. We manufacture machines with varying capacities from 5 to 150 kg per shot.
