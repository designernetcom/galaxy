Three Station Cold Box Core Shooter Machine

This is a very high productivity machine. It has three stations for shooting, gassing and core collection. It has provision of mounting three core boxes at the same time. The core boxes are mounted on a rotating table. The rotary mechanism is operated by means of chain drive, gear box and brake motor arrangement. We manufacture machine with varying capacities of up to 25 kg per station. As the cycle starts, the first core box goes to shooting station. Once the shooting operation is completed, the table then rotates and first core box moves further to gassing station. Simultaneously, the second core box moves to shooting station. Once gassing is completed, the first core box moves to core collection station where the core is retrieved. The rotating table keeps on rotating the core boxes among these three stations. Hence, a very high rate of production is achieved. A single machine can produce thrice as many cores as compared to single station in almost same cycle time.

Vertical Machine

The operation of the machine is same as mentioned earlier. In this machine, one half is fixed with self ejection mechanism. The other half is moving with cylinder operated mechanism. The three fix halves rotate on the table while the three moving halves are stationary.

Horizontal Machine

The operation of the machine is same as mentioned earlier. In this machine, the bottom halves are fixed on the rotating table. The top half are movable and are placed on the bottom halves. The top half is lifted with cylinder operated lifter mechanism core collection station.

Semi-Automatic Horizontal Machine

The operation of the machine is same as mentioned earlier. In this machine, the bottom halves are fixed on the rotating table. The top half are movable and are placed on the bottom halves. The top half is lifted and kept back manually at the core collection station. If required, the entire core box can be removed and placed back on the mounting place manually.
