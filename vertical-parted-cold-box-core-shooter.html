Vertical Parted Cold Box Core Shooter

These machines are used to manufacture cores using vertically parted core box. This type of core box has a right and a left half with vertical parting line. We manufacture vertically parted cold box core shooter machines of varying capacities from 5 to 120 kg per shot.

Features

  • Robust design and sturdy construction
  • High dimensional accuracy and precision
  • Quick changing of dies
  • Fully automatic PLC based control with display unit
  • Fault diagnostics for troubleshooting
  • Safety enclosure, laser beam safety curtain and safety interlocks
  • Pneumatic and hydraulic models available
  • Auto core ejection mechanism
  • Amine gas generation unit
  • Core taker arrangement for heavy weight cores

  • Vertical Parted – One Half Fixed And One Moving And Tilting Through 90o
  • Vertical Parted – LHS RHS Halves Moving With Mandrel Trolley

One Half Fixed And One Half Moving

In this model, one half of core box is fixed with cylinder operated ejection. The other half is moving and is provided with spring operated self ejection mechanism. After completion of cycle, the core remains in the fixed half and is removed by pressing foot switch to eject core. The machine can also be provided with fixed mandrel in order to make cores hollow.

One Half Fixed And One Moving And Tilting Through 90o

In this model, one half of core box is fixed with cylinder operated ejection. The other half is moving and is provided with spring operated self ejection mechanism. After completion of cycle, the core remains in the fixed half and is removed by pressing foot switch to eject core. The machine can also be provided with fixed mandrel in order to make cores hollow.

LHS RHS Halves Moving With Mandrel Trolley

In this model, both the halves of the core box are moving. A carrier trolley is provided with mandrel mounted on it. As the cycle starts, the mandrel trolley moves in and the two halves of core box clamp. After completion of the cycle, the core comes out of machine on the mandrel carrier trolley. The core can be collected by the operator. The bottom mandrel makes core hollow saving time and cost of core making.

Way Parted Amine Cold Box Core Shooter

In this model, the left half of core box is fixed. The right half is moving. Additionally, mandrels are provided from front, rear and bottom to make the core hollow. Such arrangement reduces the weight of core substantially. Thus, maximum amount of time, cost and material saving is achieved using this model.
