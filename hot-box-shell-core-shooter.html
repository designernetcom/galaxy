Hot Box / Shell Core Shooter

Shell core shooters are used particularly to manufacture smaller cores with intricate design and thin walls. The process uses resin coated sand that solidifies when exposed to heat. The resulting cores have high psi strength. The heating can be done by electric or gas fuelled heaters. Galaxy manufactures fully automatic shell core shooters suitable to produce cores with vertical and horizontal parted core boxes. Both pneumatic and hydraulic models are available with auto ejection mechanism for cores. Our machines are suitable to mount multi-cavity core boxes thus producing multiple cores in a single cycle. The machine cycle is controlled by means of a PLC with display unit. Safety interlocks and fault diagnostics are provided to ensure both machine and human safety.

Automatic Top Blow Vertical Parted Shell Core Shooter

This machine is suitable to manufacture cores using a vertically parted core box. In this arrangement, one half of core box is fixed with spring operated self ejection mechanism. The other half is moving. After completion of cycle, the core remains in the fixed half and is removed by pressing foot switch to eject core. An additional tilting arrangement for tilting half can be provided if necessary. Here after completion of cycle, the moving half parts from the fixed half and tilts through 90o. The core is then ejected on a core carrier trolley that brings the core out of the machine. The operator can then collect the core. We manufacture machines of varying capacities of up to 50 kg per shot.

Automatic Top Blow Horizontal Parted Shell Core Shooter

This machine is provided with bottom carrier trolley and top lifter assembly. The bottom half of the core box is fixed on core carrier trolley while the top half is movable. At the beginning of cycle, both halves of core box enter machine on the core carrier trolley. After shooting, gassing and purging operations the core carrier trolley comes out. The top half is lifted by top lifter assembly. The core can now be collected by the operator. We manufacture machines of varying capacities of up to 50 kg per shot.

Roll Over Shell Core Shooter

Roll Over Shell Core Shooter type of machine is specially designed to make cores hollow from inside. The roll over mechanism is operated by means of chain drive, gear box and brake motor arrangement. After the sand is shot into the core box cavity, the roll over arrangement turns the core box upside down. As a result, excess sand flows down and is collected in sand collection tank. As a result a substantial amount of material and costs are saved. We manufacture machine with varying capacities of up to 25 kg per station.
